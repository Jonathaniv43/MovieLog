
# MONOREPO MOVIELOG
MovieLog es una aplicación orientada al registro de películas que el usuario ha visto. Su propósito es permitir mantener un **historial de películas y utilizar esa información como base para generar recomendaciones personalizadas.**



## Funcionalidades

Actualmente, el proyecto se centra en la gestión del catálogo de películas, permitiendo:

- Registrar películas.
- Consultar todas las películas disponibles.
- Consultar una película específica.
- Actualizar información de una película.
- Eliminar películas.
- Validar los datos antes de almacenarlos.

Como parte de su evolución, MovieLog podrá utilizar el historial de películas vistas para generar recomendaciones basadas en las preferencias del usuario.
